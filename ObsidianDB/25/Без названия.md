### Инструменты разработки (исправлено)
- **VS Code + Remote SSH** — основная IDE для C++ на Linux
- **CLion** — если доступен, для сложных C++-проектов
- **Vim/Nano** — только для быстрого редактирования конфигов
- **Не** использовать Vim как основную IDE на этом этапе

### Linux: что учить в год 1
- Терминал как основная среда (не GUI)
- Bash: скрипты, пайпы, redirect, переменные окружения
- Управление процессами: ps, top, kill, systemctl
- Файловая система: права, ownership, chmod, chown
- Пакетный менеджер: apt
- SSH: удалённый доступ
- Окружение: PATH, env vars, .bashrc
