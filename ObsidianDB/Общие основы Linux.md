
## Что такое Linux? Чем отличаются Linux, GNU/Linux и дистрибутив?

Linux - это ядро, на которой уже строится полноценная ОС. Linux реализует предоставляет механизмы для работы с памятью, сетью, процессором, файловой системой и т.д.
`Linux` часто упоминают совместно с `GNU`. `GNU` (`GNU's Not Unix`)  - это проект по созданию полноценной свободной `Unix`-подобной операционной системы. `Linux` объеденился с `GNU`, что позволило создать огромное количество рализных ОС.
Если подытодить:
1) Linux (`kernal space`) - это ядро ОС
2) `GNU/Linux` (`user space`) предоставяет набор команд и утилит для работы с ядром ОС - `Linux`.
3) Дистрибутив (`user space`) - это полноценная ОС с пакетным менеджером, репозитием и набором утилит для комфортной работы пользователей
