
## Что такое Linux? Чем отличаются Linux, GNU/Linux и дистрибутив?

Linux - это ядро, на которой уже строится полноценная ОС. Linux даёт набор команд для работы с памятью, сетью, процессором, файловой системой и т.д.
Дистрибутив Linux - это полноценная ОС, которая состоит из ядра Linux, утилит GNU (`GNU’s Not UNIX`) и различных предуставноленных пакетов.
`GNU` - это проект по созданию полноценной операционной системы
