**Пример (Алгоритм захвата mutex)**
```text
Твой код:
    std::mutex::lock()
          ↓
Реализация стандартной библиотеки C++
          ↓
    pthread_mutex_lock()
          ↓

    атомарная попытка захвата
          │
          ├── успех → возврат в твой код
          │
          └── конкуренция → медленный путь
                               ↓
                         системный вызов futex
                               ↓
                         ядро Linux
                               ↓
                     ожидание / планировщик
```

### Что такое futex

futex (fast user-space mutex) - 

`futex(address, FUTEX_WAKE, 1)` - разбуди 1 поток по данному адресу
`futex(address, FUTEX_WAIT, expected_value)` - усыпи текущий поток, если по адресу все еще лежит `expected_value`

Почему важно будть только 1 поток? Этот эффект назыается "thundering herd" (грохочущего стада), при выходе из mutex-а, скорее всего, его захватит лишь один новый поток, соотвественно "будить" все потоки не имеет никакого смысла

```
0 - свободен
1 - захвачен
2 - захвачен; есть или могут быть ожидающие
```

```
|   |

|{|

|_shared mapping, so synchronization with another process is needed_|

|**if** (private == LLL_PRIVATE && SINGLE_THREAD_P && mutex->__data.__lock == 0)|
|mutex->__data.__lock = 1;|
|**else**|
|lll_lock (mutex->__data.__lock, private);|
|}|
```
