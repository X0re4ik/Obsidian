

Конструктор `std::thread`:
```
thread(_Callable&& __f, _Args&&... __args) {}
```

Стандарт говорит, что вызов функции внутри потока будет идентичен конструкции ниже 
```
std::invoke(
	decay_copy(std::forward<F>(f)),
    decay_copy(std::forward<Args>(args))...);
```
