
Каждое значение в `C++` характеризуется двумя независимыми свойствами: _[тип](https://ru.cppreference.com/cpp/language/type "cpp/language/type")_ и категория значения. Каждое выраженеи может находиться **только в одном** из трёх категорий значений: prvalue, xvalue, lvalue

**Иерархия категорий значений:**
```text
							 expression
							 /         \
						glvalue       rvalue
						/    \        /    \
					lvalue   xvalue prvalue xvalue
```

Полный список `lvalue` значений перечислен [здесь](https://ru.cppreference.com/cpp/language/value_category), перечислим лишь наиболее типичные:
* Любое именованнное выражение. Если объект имеет название значит он `lvalue`, в т.ч. объекты параметра шаблона
* Идексирование `a[n]`
* Операции **пре**инкремента `++a` 
* Разыменование указателя `*ptr`
* Выражение элемента объект `a.m`, кроме случаев, когда `a` является `rvalue`, в т.с. `m` также является `rvalue`
* Строковые литералы `Hello Wolrd`
Свойства `lvalue`:
* Адресс `lvalue` можно получить встроенным оператором `&`
**Например**
```C++
User &make_user_ref() {
  User u{"Anton"};
  return u;
}

User make_user() {
  return {"Anton"};
}

int main() {
    std::cout << &(make_user_ref().name); // OK
    std::cout << &(make_user().name); // Compiler Error
}
```
* Изменяемое `lvalue` может использоваться, как левый операнд для любых операций
* `lvalue` может использоваться для инициализации ссылки на `lvalue`
* Константная ссылка на `lvalue` может привязываться к `rvalue`. При этом создаётся временный объект, и его время жизни продлевается до времени жизни ссылки

Полный список `prvalue` значений перечислен [здесь](https://ru.cppreference.com/cpp/language/value_category), перечислим лишь наиболее типичные:
* Операции **пост**инкремента `a++`
* Любые арифметические операции `a+b`
* Все литералы (кроме строковых) `true`, `43`
* Вызов функции, возвращаемый тип, которых не является ссылочным
**Например**
```C++
// lvalue
User &make_user_ref() {
  User u{"Anton"};
  return u;
}

// prvalue
User make_user() {
  return {"Anton"};
}
```
* Выражение приведения к не ссылочному типу: `static_cast<double>(x)`, `std::string{}`, `(int)42`
* Указатель `this`
Свойства `prvalue`:
* `prvalue` - это чистое знаачение, у него нет идентичности объекта, нет адреса, нет полим
* `prvalue` не может быть полиморфным, потому что для полиморфизма необходима ссылка или указатель - `lvalue`
