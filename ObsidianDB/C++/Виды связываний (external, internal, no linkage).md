

Наша программа для компилятора одна большая книга, в ней есть главы, страницы, ссылки на другие главы и, конечно же, картинки.
Представим, что каждая глава для компилятора - это одна единица трансляции, в каждый главе может быть сслыка на другую главу.

У каждой переменной и функции есть правило видимости:

1) Внешнее связывание

Данная функция/переменная будет видна всем другим единицам трансляции

2) Внутреннее связывание

Данная функция/переменная будет видна только в рамках своей единице трансляции

3) Отсутствие связывания

Сущность существует только в рамках одного блока



Чем отличается Static от Анономного пространства имён

static - это спецификатор класса памяти (storage class specifier).
