## Как Valgrind исполняет мою программу?

Valgrind не просто наблюдает за работающей программой, а запускает ее через собсвтенную среду исполнения. Все инструкции машинного кода, котороые исполняет программ проходят через Valgrind.

**Например:**
```text
Было:
app → CPU → Linux kernel / память / устройства

Стало:
app → Valgrind → CPU → Linux kernel / память / устройства
```



| Категория         | Есть путь к блоку на завершении?          | Можно штатно освободить?      | Типичный приоритет         |
| ----------------- | ----------------------------------------- | ----------------------------- | -------------------------- |
| `definitely lost` | Нет                                       | Нет                           | Исправлять обязательно     |
| `indirectly lost` | Только через потерянный блок              | Нет, пока не исправлен корень | Исправлять корневую утечку |
| `possibly lost`   | Есть лишь подозрительный указатель внутрь | Неясно                        | Расследовать               |
| `still reachable` | Да, есть нормальный путь                  | Да                            | Оценить контекст           |
| `suppressed`      | Отчёт скрыт правилом suppression          | Зависит от причины            | Проверить suppression      |
