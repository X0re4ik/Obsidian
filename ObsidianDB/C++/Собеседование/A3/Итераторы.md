
## Введение в итераторы

Основные виды итераторов в `C++`:

1) Input - данные движутся только вперед и только на чтение

**Пример**
```C++
std::istringstream input{"10 20 30"};

std::istream_iterator<int> it(input);
std::istream_iterator<int> end;

while (it != end) {
    int value = *it;
    ++it;
}
```

2) `Output` - итератор способный только на запись элементов, не умеет читать. поддерживает только операцию вперед (`++it`)

**Пример**
```C++
std::vector<int> v;
std::copy(v.begin(), v.end(),
          std::ostream_iterator<int>(std::cout, " "));
// v = {1, 2, 3}

std::vector<int> dst;
std::copy(v.begin(), v.end(), std::back_inserter(dst));
// dst = {1, 2, 3}
```

3) `Forward` - читать, писать, обходить диапазон многократно, но **только** вперед

**Контейнеры:** `std::forward_list`, `std::unordered_set`, `std::unordered_map`

**Операции:** `it++`; `*it`

4) `Bidirectional` - поддерживает все возможности `Forward`, но включает также движение назад

**Контейнеры:** `std::list`, `std::set`, `std::map`, `std::multiset`, `std::multimap`

**Операции:**
```C++
it++        // ✅ Движение вперед
it--        // ✅ Движение назад
it + 1      // ❌ Ошибка компиляции
```

**Пример**
```C++
std::list<int> x{1, 2, 3, 4};
auto it = std::begin(x);
std::cout << *(++it) << '\n'; // 2
std::cout << *(--it) << '\n'; // 1
```

5) `Random-access` - поддерживает "прыжки" по объекту

**Контейнеры:** `std::vector`, `std::deque`, `std::array`

**Операции:**
```C++
it1 < it2;     // ✅ Порядковое сравнение
it2 - it1;     // ✅ Число шагов между итераторами
it + n;        // ✅ Сдвиг
it[n];         // ✅ Доступ со смещением
```

**Пример**
```C++
std::vector<int> input{1, 2, 3, 4, 5};
auto it = std::begin(input);
std::cout << *(it + 3) << '\n'; // 4
```

6) `Contiguous` - усиление `random_access_iterator` для контейнеров, что располагают данные в памяти сплошным блоком (такие как `std::vector` и `std::arary`)

Для подобных итераторов справедливо:

```C++
std::vector<int> v{10, 20, 30};

auto it = v.begin();

std::cout << it[1];              // 20
std::cout << *(it + 2);          // 30

int* p1 = std::to_address(it);
int* p2 = v.data();

assert(p1 == p2);
```

Яркий представитель подобных контейнеров с `contiguous` итератором: `std::span`, который содержит лишь указатель на начало блока и его размер, что делает его легковестным и `C API` совместимым

## Иерархия возможностей

```C++
input
  └── forward
        └── bidirectional
              └── random access
                    └── contiguous

output — отдельная категория для последовательной записи
```

## Кейсы с собеседований

### Вопрос №1

```C++
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    v.reserve(4);

    v.push_back(10);
    v.push_back(20);

    auto it = v.begin();
    int* p = v.data();
    auto old_end = v.end();

    v.push_back(30);

    std::cout << *it << ' ' << *p << '\n';
    std::cout << (old_end == v.end()) << '\n';
}
```

**Вопрос:** Что выведет эта программа? Будет ли в ней undefined behavior? Объясни состояние `it`, `p` и `old_end` после `push_back`.

**Ответ:**
1) Вывод програмы:
```text
10 10
false
```
2) `UB` не будет, потому что в станлартной реализации `std::vector` при `size == capacity` происходит релокация памяти, а у нас `size = 3; capacity = 4` - есть запас в 1 объект. Но стоит отметить, что `old_end` больше не валиден, так как вектор `v` имеет новый размер, а `old_end` указывает за объектом `20`, то есть на `30`

### Вопрос №2

```C++
std::vector<int> v{1, 2, 3, 4, 5, 6};

for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it % 2 == 0) {
        v.erase(it);
    }
}
```

**Вопрос:** Нужно удалить из `std::vector` все чётные числа. Этот код корректен? Если нет, объясни, что произойдёт, и исправь.

**Ответ:**
1) Код некоректен, потому что после удаление элемента происходит "сдвиг" элементов влево, что делает итератор `it` невалидным. `erase` возвращает валидный итератор на следующий после удаления элемент `it = v.erase(it)`
2) Варианта исправления два:

Вариант 1:
```C++
std::vector<int> v{1, 2, 3, 4, 5, 6};

for (auto it = v.begin(); it != v.end();) {
    if (*it % 2 == 0) {
        it = v.erase(it);
    }
    else {
	    ++it;
    }
}
```

Вариант 2:
```C++
std::vector<int> v{1, 2, 3, 4, 5, 6};

// erase-remove idiom
v.erase(
	std::remove_if(
		v.begin(),
		v.end(),
		[](int x){ return x % 2 == 0; }
	),
    v.end()
);

// C++20
std::vector<int> v{1, 2, 3, 4, 5, 6};
std::erase_if(v, [](int x) {
    return x % 2 == 0;
});
```

### Вопрос №3

```C++

struct Item {
    int id;

    Item(int id) : id(id) {}

    Item(const Item&) = delete;

    Item(Item&& other) noexcept : id(other.id) {
        other.id = -1;
    }
};

int main() {
    std::vector<Item> v;
    v.reserve(2);

    v.emplace_back(10);
    v.emplace_back(20);

    Item& first = v[0];
    Item* raw = &v[1];

    v.reserve(10);

    std::cout << first.id << ' ' << raw->id << '\n';
}
```

**Вопросы:**
1) Компилируется ли программа?
2) Что происходит на `v.reserve(10)`?
3) Валидны ли `first` и `raw` после `reserve(10)`?
4) Можно ли считать, что программа гарантированно выведет `10 20`?
5) Почему здесь важен `noexcept` у move-конструктора?

**Ответы:**
1) Программа компилируется
2) `v.reserve(10)` - мы алоцируем память для 10 объектов типа `Item`
3) Нет, это `UB`, так как, скорее всего, при релокации памяти мы выделили новый блок и все объекты **перенесли** туда, что привело к инвалидации объектов `first` и `raw`
4) Нет
5) Здесь крайне важен `noexcept` у конструктора, все потому что его наличие обеспечивает перемещение объектов при релокации памяти, когда происходит релокация, то `std::vector` выбирает между конструктором копирования и перемещения и выбирает перемещение, если он безопасен (не кидает исключений). Отметим, что программа соберется и с `noexcept` и без него.
