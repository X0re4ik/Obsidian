# А2. Краткий ответ по вопросам ДЗ№2

## Общие знания по ООП

### 1. Что такое ООП?

**ООП (Объектно-ориентированное программирование)** - это методология программирования, в которой программа строится из объектов, объединяющих данные и методы их обработки. Основные принципы: инкапсуляция, наследование и полиморфизм.

[[Общие знания по ООП#Что такое ООП?|Полный ответ]]

### 2. Что такое класс?

**Класс** - это шаблон (чертёж) для создания объектов, описывающий их свойства (поля) и поведение (методы)

[[Общие знания по ООП#Что такое класс?|Полный ответ]]

### 3. Что такое объект?

**Объект** - это экземпляр класса, конкретная сущность, созданная по шаблону, со своими 
значениями свойств и доступными методами

[[Общие знания по ООП#Что такое объект?|Полный ответ]]

### 4. Расскажи про основные принципы ООП: абстракция, наследование, полиморфизм, инкапсуляция.

**Инкапсуляция** - размещение в одном компаненте данных и методов, которые с ним работают

**Наследование** - механизм, который позволяет создавать новый класс на основе уже существующего, заимствуя его поля и методы

**Полиморфизм** - это способность обьекта использовать методы производного класса, который не существует на момент создания базового.

[[Общие знания по ООП#Расскажи про основные принципы ООП: абстракция, наследование, полиморфизм, инкапсуляция.|Полный ответ]]

### 5. Что такое АБК (Абстрактный Базовый Класс)? Что такое интерфейс?

АБК -  это базовый класс, который который опредляет набор методов и полей, которые должны быть в любом дочернем классе. Его нельзя инстанцировать.

Интерфейс - это контракт, который определяет, чаще всего, один или несколько методов, которые должны следовать классы наследники.

### 6. Расскажи про принципы SOLID.

SOLID:

* S - Класс должен закрывать только одну потребность.
* O - Класс должен быть открыт для расширения, но закрыт для модификации.
* L - Каждый объект в классе может быть заменен на экземпляр их подтипов без изменения работы программы.
* I - Много специализированных интерфейсов лучше, чем один универсальный.
* D - Верхние уровни абстракции не должны зависеть от нижних уровней абстракции и наоборот.

[[Общие знания по ООП#Расскажи про принципы SOLID.|Полный ответ]]

### 7. Что такое модификаторы доступа? Расскажи про public, private, protected.

**public:** - полная открытость данных, клиент может свободно обращаться к методам и полям в блоке public

**private** - полная закрытость данных, ни клиент, ни дочерний класс не может получить поля или вызвать методы в блоке private

**protected** - открытость полей и методов только для очерних классов, то есть наследник может вызвать методы родителя, но внешнму клиенту вызов protected блока запрещен

В `C++` все поля `struct`-ы по умолчанию `public`, а все поля класса `private`
