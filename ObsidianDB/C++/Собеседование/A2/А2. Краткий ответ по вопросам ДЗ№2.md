# А2. Краткий ответ по вопросам ДЗ№2

## Общие знания по ООП

### 1. Что такое ООП?

ООП — парадигма программирования, в которой программа строится из взаимодействующих объектов, объединяющих состояние и поведение. Основные принципы: абстракция, инкапсуляция, наследование и полиморфизм.

[[Общие знания по ООП#Что такое ООП?|Полный ответ]]

### 2. Что такое класс?

Класс — пользовательский тип данных, определяющий поля, методы и правила доступа к ним. Он описывает состояние и поведение своих экземпляров — объектов.

[[Общие знания по ООП#Что такое класс?|Полный ответ]]

### 3. Что такое объект?

В контексте ООП объект — экземпляр класса со своим состоянием и временем жизни. Его поведение определяется методами класса. Нестатические поля принадлежат отдельным объектам, статические поля общие для класса.

[[Общие знания по ООП#Что такое объект?|Полный ответ]]

### 4. Расскажи про основные принципы ООП: абстракция, наследование, полиморфизм, инкапсуляция.

Абстракция — выделение существенных свойств и скрытие ненужных деталей.
Инкапсуляция — объединение данных и методов с контролем доступа к внутреннему состоянию.
Наследование — создание производного класса на основе базового.
Полиморфизм — работа через общий интерфейс с разными реализациями; например, вызов переопределённых виртуальных методов через указатель на базовый класс.

[[Общие знания по ООП#Расскажи про основные принципы ООП: абстракция, наследование, полиморфизм, инкапсуляция.|Полный ответ]]

### 5. Что такое АБК (Абстрактный Базовый Класс)? Что такое интерфейс?

АБК — базовый класс, в котором хотя бы одна виртуальная функция остаётся чистой (`= 0`). Его экземпляр создать нельзя; он может содержать поля и реализацию методов. Интерфейс — контракт доступных операций. В C++ его обычно выражают абстрактным классом с публичными чистыми виртуальными методами и виртуальным деструктором, без состояния.

[[Общие знания по ООП#Что такое АБК (Абстрактный Базовый Класс)? Что такое интерфейс?|Полный ответ]]

### 6. Расскажи про принципы SOLID.

S — у класса одна ответственность, одна причина для изменения.
O — код открыт для расширения, закрыт для модификации.
L — подтип должен заменять базовый тип без нарушения его контракта.
I — клиент не должен зависеть от методов, которые не использует.
D — высокоуровневые и низкоуровневые модули зависят от абстракций; детали зависят от абстракций, а не наоборот.

[[Общие знания по ООП#Расскажи про принципы SOLID.|Полный ответ]]

### 7. Что такое модификаторы доступа? Расскажи про public, private, protected.

Модификаторы доступа определяют, откуда доступны члены класса.
`public` — из любого кода, где доступен объект или тип.
`private` — из методов и друзей самого класса.
`protected` — также из методов и друзей производных классов, с ограничениями доступа через объект.
По умолчанию в `class` доступ `private`, в `struct` — `public`.
