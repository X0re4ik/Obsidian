
**Что такое конструктор?**

Особый вид метода класса, который автоматически вызывается при создании объекта класса
Особенности конструктора:
* Название идентично названию класса
* Не имеет возвращаемого значения

**Существует ли виртуальный конструктор?**

Нет! Виртуальных конструкторов быть не может.


**Какие виды конструкторов ты знаешь?**

1) Конструктор по умолчанию
Генерируется компилятором по умолчанию, если контруктор не объявлен, так как у каждого объекта обязан быть конструктор

2) Консруктор с параметрами
Если мы хотим явно создавать объект из опредленных параметров, то используем этот вид контрукторов. Конструкторам с параметрами разрешены перегрузки, поэтому на них распостраняются все правила разрешения перегрузок

3) Конструктор копирования (Copy Constructor)
**Создание по умолчанию:** ДА. Компилятор генерирует поверхностное копирование объекта (shallow copy)
**Описание:** Конструктор копирования производит копирование всех полей в новый объект
**Сигнатура:**
```C++
Foo(const Foo &foo);
```
**Примеры:**
Посмотрим на простую реализацию конструктора копирования:
```C++
class Foo {
private:
  int a_;

public:
  Foo(const Foo &foo) { a_ = foo.a_; }
};
```
Конструктор копирования принимает `const &` на объект того же типа и имеет доступ к приватным полям класса. Пример выше немного искусственный, так как нам бы подошла и стандартная реализация конструктора копирования

Рассмотрим более сложный вариант:
```C++
class Foo {
private:
  int *a_;

public:
  Foo(const Foo &foo) : a_(new int{*foo.a_}) {}
};
```
В примере выше (если опустить, что `_a` может принимать форму `nullptr`) мы вынуждены самим реализовывать конструктор копирования, иначе компилятор просто реализует за нас, что-то на подобии `Foo(const Foo &foo) : a_(foo.a_)`

### 8. Что такое виртуальная функция?

Виртуальная функция — это функция-член, которую предполагается переопределить в производных классах. Отличительная черта виртуальных функций — наличие ключевого слова `virtual`.

Чтобы наглядно рассмотреть роль `virtual`, рассмотрим следующий пример:

```cpp
#include <iostream>

class Base {
public:
  virtual void NameOf() { std::cout << "Base: NameOf" << std::endl; }
  void InvokingClass() { std::cout << "Base: InvokingClass" << std::endl; }
};

class Derived : public Base {
public:
  void NameOf() override { std::cout << "Derived: NameOf" << std::endl; }
  void InvokingClass() { std::cout << "Derived: InvokingClass" << std::endl; }
};

int main() {
  Derived aDerived;
  Base *pBase = &aDerived;
  pBase->InvokingClass(); // (2)
  pBase->NameOf();        // (3)
  return 0;
}
```

Пример выше выведет следующее значение:
```text
Base: InvokingClass
Derived: NameOf
```

Здесь наглядно продемонстрировано правило работы вызова виртуальных и невиртуальных функций:
* Вызов виртуальной функции разрешается в соответствии с динамическим (то есть фактическим) типом объекта, для которого она вызывается.
* Вызов невиртуальной функции разрешается в соответствии с типом указателя или ссылки (статическим типом).

Механизм виртуальных функций можно "подавить" при помощи явного указания базового класса и оператора разрешения видимости (`::`).
Например:

```cpp
int main() {
  Derived aDerived;
  Derived *pDerived = &aDerived;
  pDerived->Base::NameOf();
  return 0;
}
```

Начиная с C++11 появилось ключевое слово `override`, которое позволяет явно сказать компилятору, что эта функция переопределяет виртуальную функцию родителя. Это позволяет нам избавиться от ошибок, когда вместо переопределения мы случайно создали новый метод с чуть иными параметрами.

```cpp
class Base {
public:
  virtual void NameOf() { std::cout << "Base: NameOf" << std::endl; }
};

class Derived : public Base {
public:
  void NameOf() override { std::cout << "Derived: NameOf" << std::endl; }
};
```

У виртуальных функций есть еще одна возможность: они способны превращать классы в абстрактные. Если хотя бы 1 виртуальная функция объявлена как **чистая виртуальная функция** (при помощи `= 0`), то весь класс является абстрактным. Создать экземпляр (объект) абстрактного класса невозможно.

```cpp
class Base { // Абстрактный класс
public:
  virtual void NameOf() = 0; // Чистая виртуальная функция
};
```
