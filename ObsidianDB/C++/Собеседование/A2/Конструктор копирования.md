


**Создание по умолчанию:** ДА. Компилятор генерирует поверхностное копирование объекта (shallow copy)
**Описание:** Конструктор копирования производит копирование всех полей в новый объект
**Сигнатура:**
```C++
Foo(const Foo &foo);
```
**Примеры:**
Посмотрим на простую реализацию конструктора копирования:
```C++
class Foo {
private:
  int a_;

public:
  Foo(const Foo &foo) { a_ = foo.a_; }
};
```
Конструктор копирования принимает `const &` на объект того же типа и имеет доступ к приватным полям класса. Пример выше немного искусственный, так как нам бы подошла и стандартная реализация конструктора копирования

Рассмотрим более сложный вариант:
```C++
class Foo {
private:
  int *a_;

public:
  Foo(const Foo &foo) : a_(new int{*foo.a_}) {}
};
```
В примере выше (если опустить, что `_a` может принимать форму `nullptr`) мы вынуждены самим реализовывать конструктор копирования, иначе компилятор просто реализует за нас, что-то на подобии `Foo(const Foo &foo) : a_(foo.a_)`


### Правило трех

**Правило трёх** сформулировал *Скотт Мейерс* в своей книге "Effective C++"
>Если классу необходим один из следующих методов, то скорее всего ему понадобятся и два других: Деструктор, Конструктор копирования, Оператор присваивания копированием


## Разбор кейсов

**Вопрос:** Почему программа падает с ошибкой`free(): double free detected in tcache 2` 
```C++
class Image {
private:
  char *pixels_;

public:
  Image() : pixels_(new char[1024]) {}

  Image(const Image &other) : pixels_(new char[1024]) { // (2)
    std::memcpy(pixels_, other.pixels_, 1024);
  }

  ~Image() { delete[] pixels_; }
};

int main() {
  Image img1;
  Image img2;
  img2 = img1; // (1)
  return 0;
}
```
**Ответ:** Это пример демонстрирующий пренебрижение правилом трёх, мы видим деструктор, конструктор копирования, но нет **оператора присвоения копированием**. Из-за это причины `(1)` не вызывает `(2)`, решить можно при помощи блока `(3)`:
```C++
Image &operator=(const Image &other) { // (3)
	if (this != &other) {
		delete[] pixels_;
		pixels_ = new char[1024];
		std::memcpy(pixels_, other.pixels_, 1024);
	}

	return *this;
}
```
