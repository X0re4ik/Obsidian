## Что такое RVO? Напиши код.

RVO - (Return Value Optimization) - оптимизация компилятора, позволяющая в некоторых случаях не создавать локальный объект, который будет использован как возвращаемое значение

RVO неразрывно связано с понятием `prvalue` (`pure value`)

Что происходит с кодом без `RVO` (флаг `-fno-elide-constructors` в `g++` компиляторе):
```C++
class A {
public:
  A() { std::cout << "A()" << std::endl; }
  A(const A &) { std::cout << "A(const A&)" << std::endl; }

  ~A() { std::cout << "~A()" << std::endl; }
};

A getA() {
  return A(); // (1)
}

int main() {
  auto a = getA(); // (2)
  return 0;
}

//main.cpp
A()
A(const A&)
~A()
~A()
```
Создание объекта `a`  сотоит из нескольких этапов:
1) Создание временного объекта внтри функции `getA`
2) Копирование/Перемещение временного объекта в переменную `a`
3) Вызов деструктора для временного объекта

До `C++17` применение `RVO` было **не обязательным**, то есть компилятор сам решал, использовать `RVO` или нет. После `C++17` `RVO` является обязательным.
```After C++17.txt
A()
~A()
```

Рассмотрим пул сценариев, когда отрабатывает `RVO`:

1) Возврат временного объекта (`prvalue`) 🟢
```C++
A getA() {
  return A();
}
```
2) Возврат локального объекта (`NRVO`) 🟡
`NRVO` не является обязательным даже после `C++17`, но большинство компиляторов ее используют
```C++
A getA() {
  auto x = A();
  return x;
}
```
3) Возврат различных объектов в зависимости от условия 🔴
```C++
A getA(int x) {
  if (x > 0) {
    auto x = A();
    return x; // RVO не сработает
  } else {
    auto y = A();
    return y; // RVO не сработает
  }
}
```
Компилятор не может точно сказать, какой объект будет, поэтому не может применить `RVO` на месте
4) `RVO` не сработает при возврате параметра объекта 🔴
```C++
A getA(A a) {
  return a;
}
```
5) Возврат значения через `std::move`
```C++
A getA() {
  auto tmp = A();
  return std::move(tmp); // Не использовать Анти-паттерн
}
```
Использования `std::move` в `return` является антипаттерном, так как компилятор может применить `RVO` для временной переменной и если не получится применит перемещение. Явное написание `std::move` фактически требует вызова конструктора перемещения для объекта.

## Что такое NRVO? Напиши код.

`NRVO` (`Name Return Value Optimization`) - частный случай `RVO`, связанный с возвратом именнованных локальных объектов из функции.

```C++
A getA() {
  auto x = A();
  return x; // NRVO
}
```
