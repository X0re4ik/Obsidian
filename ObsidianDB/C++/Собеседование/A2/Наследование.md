
## Что такое наследование? Какие виды наследования (`public`, `protected`, `private`) ты знаешь? В чём разница между ними?

**Наследование** - это механизм, позволяющий создать объявить класс на основе уже существующего, заимсвуя его поля и методы 

`C++` поддерживает 3 **режима наследования**: `public`, `private`, `protected`

Они определяют, какую видимость получат унаследованные члены `A` внутри `B` и для внешнего кода, работающего с `B`.
Например:
```C++
class A {
public:    void pub()  { }
protected: void prot() { }
private:   void priv() { }   // недоступен никому, кроме A и friend
};

// ---- public ----
class B : public A {
    void test() { pub(); prot(); }   // ✅ pub, prot доступны внутри
};
// Клиент: b.pub() ✅, b.prot() ❌
// Наследник B: видит pub, prot ✅

// ---- protected ----
class C : protected A {
    void test() { pub(); prot(); }   // ✅ pub, prot доступны внутри
};
// Клиент: c.pub() ❌, c.prot() ❌
// Наследник C: видит pub, prot ✅ (стали protected)

// ---- private ----
class D : private A {
    void test() { pub(); prot(); }   // ✅ pub, prot доступны внутри
};
// Клиент: d.pub() ❌, d.prot() ❌
// Наследник D: НЕ видит pub, prot ❌ (стали private)
```

## Что такое множественное наследование?

`С++` поддерживает множественное наследование. Это когда один класс имеет двух и более родителей.

**Пример**
```C++
struct A { foo(); }
struct B { bar(); }

struct C : public A, public B {};
```

## Что такое ромбовидное наследование (diamond problem)? Как его избежать?

**Пример ромбовидного наследования:** 
```txt
	A
   / \
  B   C
   \ /
	D
```
```C++
class A {
public:
    int value = 42;
    void foo() { }
};

class B : public A { };
class C : public A { };

class D : public B, public C { };

D d;
d.value = 10;
// 1) Ошибка, так как у нас две копии A (Компилятор не понимает какой присвоить value=10)
// 2) Двойной вызов контруктора
```
```C++
Объект D:
┌─────────────────────┐
│ B-подобъект         │
│   └─ A-подобъект #1 │  ← value = 42
│ C-подобъект         │
│   └─ A-подобъект #2 │  ← value = 42
│ D-собственные поля  │
└─────────────────────┘
```
Решение ромбовидного наследования в **виртуальном наследовании**:
```C++
Объект D:
┌─────────────────────┐
│ B-подобъект         │
│   └─ (указатель на A)│──┐
│ C-подобъект         │  │
│   └─ (указатель на A)│──┤
│ D-собственные поля  │  │
│ A-подобъект (общий) │◄─┘  ← одна копия
│   └─ value = 42     │
└─────────────────────┘
```
**Пример из стандартной библиотеки:**
```C++
namespace std {
    class ios : virtual public ios_base { };
    class istream : virtual public ios { };
    class ostream : virtual public ios { };
    class iostream : public istream, public ostream { };
}
```


## Что такое виртуальное наследование?

Виртуальное наследование необходимо только для решения задачи ромбовидного наследования. При виртуальном наследовании мы говорим компиялтору, что наследуемый класс должен быть в одном экзмепляре. Но "грабли" всплывают в тот момент, когда мы опредляем, кто создаёт этот единственный класс? Потому что за создание отвечает самый последний в цепочке наследования.
```C++
struct A {int x;};
struct B : public A { B() : A{1} {}};
struct A {int x;};

```
