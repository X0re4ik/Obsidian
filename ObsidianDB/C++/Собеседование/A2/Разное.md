

## Расскажи, как устроена лямбда

Опредлимся с терминологией
**Функциональный объект** - объект класса, в котором опредлён оператор `()`, что позволяет объекту такого типа вызываться как скобочки.
**Функтор** = Функциональный объект
**Лямбда-функция** - это ананимный класс-функтор который создаётся компилятором на месте.

**Например:**
```C++
int main() {
  int x;
  auto d = [&x]() { x++; };
  d();
}
// =====
int main()
{
  int x;
    
  class __lambda_6_12
  {
    public: 
    inline constexpr void operator()() const
    {
      x++;
    }
    
    // private: 
    int & x;
  };
  
  __lambda_6_12 d = __lambda_6_12{x};
  d.operator()();
  return 0;
}

```

Лямбда состоит из 3 частей: `[]`; `()`; `{}`
1) `[]` - захватчик, здесь мы перечисляем список объектов, которые хотим захватить, то есть передать в качестве параметра класса
2) `()` - аргументы, здесь мы передаём список объектов, которые должен принимать оператор `()` анонимного класса
3) `{}` - тело функции, то есть то, что будет выполнено со значениями

Мутабельные лямбды
Проблема функторов, которые создаются в `С++` - они константы, поэтому захватчик вынужден полчать объект по ссылки, так как ссылку можно изменять в константных методах класса. Но как быть, если мы хотим захватить объект по значению и изменить его в ляюбда функции - ключевое слово `mutable`, которое снимает константность с функтора

```C++
int main() {
  int x = 10;
  auto d = [x](){ x++; };
  d();
}
// =====
int main()
{
  int x = 10;
    
  class __lambda_6_12
  {
    public: 
    inline constexpr void operator()()
    {
      x++;
    }
    
    // private: 
    int x;
  };
  
  __lambda_6_12 d = __lambda_6_12{x};
  d.operator()();
  return 0;
}
```
