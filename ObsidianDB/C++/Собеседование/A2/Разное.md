

## Расскажи, как устроена лямбда

Лябда имеет простой синтаксис в `C++`: `[] (параметры) { действия }`
Лямбда в `C++` не имеют типа, так как в момент компиляции приложения создается специальный класс 

**Функциональный объект** - объект класса, в котором опредлён оператор `()`, что позволяет объекту такого типа вызываться как скобочки.

**Функтор** = Функциональный объект

**Лямбда-функция** - это ананимный класс-функтор который создаётся компилятором на месте.

**Например:**
```C++
int main() {
  auto d = []() {};
  d();
}
// =====
int main()
{
    
  class __lambda_5_12
  {
    public: 
    inline constexpr void operator()() const
    {
    }
    
    using retType_5_12 = void (*)();
    inline constexpr operator retType_5_12 () const noexcept
    {
      return __invoke;
    };
    
    private: 
    static inline constexpr void __invoke()
    {
      __lambda_5_12{}.operator()();
    }
    
  };
  
  __lambda_5_12 d = __lambda_5_12{};
  d.operator()();
  return 0;
}
```

Лямбда состоит из 3 частей: `[]`; `()`; `{}`
1) `[]` - захватчик, здесь мы перечисляем список объектов, которые хотим захватить, то есть передать в качестве параметра класса
2) `()` - аргументы, здесь мы передаём список объектов, которые должен принимать оператор `()` анонимного класса
3) `{}` - тело функции, то есть то, что будет выполнено со значениями
