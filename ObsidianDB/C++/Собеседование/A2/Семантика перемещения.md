**Что такое семантика перемещения?**

Семантика перемещения - совокупность правил языка C++, предназанченных для перемещения объектов время жизни объектов, которых скоро истечёт вместо их копирования.

В `C++` семантика перемещения реализуется через оператор move-присвоения `T& operator=(T&&)` и move-конструктор `T(T&&)`

**Пример**
```C++
struct A {
private:
  std::string str_;

public:
  A(std::string &&str) : str_(std::move(str)) {
    std::cout << "A(std::string&& str)" << std::endl;
  }

  A(const std::string &str) : str_(str) {
    std::cout << "A(const std::string &str)" << std::endl;
  }
};

A foo() {
  std::string str = "I Love C++";
  auto ret = A(str);
  std::cout << "foo: " << str.size() << std::endl;
  return ret;
}

A boo() {
  std::string str = "I Love C++";
  auto ret = A(std::move(str));
  // Потеряли владение над данными `str`, теперь данными владет `ret`
  // `str` живой и валидный, но данные забрал `ret`
  std::cout << "boo: " << str.size() << std::endl;
  return ret;
}

int main() {
  foo();
  // A(const std::string &str)
  // foo: 10
  boo();
  // A(std::string&& str)
  // boo: 0
  return 0;
}
```

**Что такое deep copy и shallow copy?**

`deep copy` - глубокое копирование объекта
`shallow copy` - поверхностное копирование объекта

При глубоком копирование объекта происходит глбокое копирование всех его полей, что может быть затратно по ресурам

Поверхностное копирование - это копирование объекта, как есть, то есть копирование только полей класса. При поверхностном копировании в случаи указателей мы можем изменять данные одного объекта через другого.
Глубокоое копирование - это копирование, при котором каждое поле класса так же подвержено глубокоому копированию. При глубоком копировании происходит полное дублирование данных, таким образом мы не можем влиять на о
