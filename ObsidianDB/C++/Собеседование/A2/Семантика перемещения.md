## Что такое семантика перемещения?

Семантика перемещения позволяет передавать ресурсы объекта — память, файловый дескриптор, сокет — новому владельцу вместо их полного копирования. Она используется, когда источник временный или больше не нужен. В C++ её поддерживают move-конструктор `T(T&&)` и move-присваивание `T& operator=(T&&)`. `std::move` не перемещает сам: он превращает выражение в xvalue, после чего выбирается move-операция. Объект-источник остаётся валидным, но его состояние не определено.

## Что такое deep copy и shallow copy?

Shallow copy — побитовое или по-польное копирование. Если класс хранит сырой указатель, копия получит тот же адрес: изменение ресурса видно через оба объекта, а два `delete` приведут к UB. Deep copy создаёт независимый ресурс и копирует его содержимое: например, `x = new int(*other.x)`. Тогда объекты не разделяют данные. Обычно лучше применять RAII: `std::string`, контейнеры и умные указатели, а не вручную управлять `new`/`delete`.

## Что такое rvalue и lvalue? Какие ещё категории значений ты знаешь?

`lvalue` — выражение с идентичностью объекта: у него можно получить адрес, например `x`. `prvalue` — чистое значение без идентичности объекта в выражении: `42`, `x + 1`. `xvalue` — объект с идентичностью, ресурсы которого можно передавать: `std::move(x)` или результат функции `T&&`. `prvalue` и `xvalue` составляют `rvalue`. Важно: наличие `&&` в типе не делает именованную переменную rvalue — `T&& arg` при использовании `arg` остаётся lvalue.

## Что делает `std::move`? Как устроен `std::move`?

`std::move` ничего сам не перемещает. Он приводит выражение к xvalue - rvalue-ссылке - чтобы следующая операция могла выбрать перемещение.
Упрощённо:
```C++
template<class T>
remove_reference_t<T>&& move(T&& x) {
    return static_cast<remove_reference_t<T>&&>(x);
}
```
Если передать lvalue `x`, то `T` выводится как `U&`. Без `remove_reference` тип `T&&` свернулся бы обратно в `U&`, и перемещения не было бы. `remove_reference_t<T>` убирает `&`, поэтому выполняется `static_cast<U&&>(x)`.
```C++
std::string a(1000, '1');
std::string b;

b = std::move(a); // выбирается operator=(std::string&&)
```
Перемещает ресурсы именно оператор присваивания `std::string`, а `std::move` лишь разрешает это. После перемещения `a` валиден, но его прежнее значение не определено.

## Что делает `std::forward`? Как устроен `std::forward`?

`std::forward<T>(x)` сохраняет исходную категорию значения аргумента в шаблоне.
Именованный параметр `arg` всегда является lvalue, даже если его тип — `T&&`. Поэтому без `forward` rvalue передастся как lvalue.
Упрощённо:
```C++
template<class T>
T&& forward(remove_reference_t<T>& x) {
    return static_cast<T&&>(x);
}
```
Если `T = U&`, `T&&` сворачивается в `U&`: результат lvalue. Если `T = U`, получается `U&&`: результат xvalue.
Использование:
```C++
template<class T>
void wrapper(T&& arg) {
    process(std::forward<T>(arg));
}
```
В отличие от `std::move`, который всегда делает xvalue, `forward` делает это только когда исходный аргумент был rvalue.
