
## Что такое Linux? Чем отличаются Linux, GNU/Linux и дистрибутив?

Linux - это ядро, на которой уже строится полноценная ОС. Linux предоставляет механизмы для работы с памятью, сетью, процессором, файловой системой и т.д., умеет работать с аппаратными ресурсами.
`Linux` часто упоминают совместно с `GNU`. `GNU` (`GNU's Not Unix`)  - это проект по созданию полноценной свободной `Unix`-подобной операционной системы. `Linux` был использован, как ядро некоторых проектов `GNU`.
Если подытодить:
1) Linux  - это ядро ОС
2) `GNU/Linux` предоставяет набор команд и утилит для работы с ядром ОС - `Linux`.
3) Дистрибутив - конкретная сборка Linux-based ОС: ядро, user space, init-система, пакетный менеджер, репозитории, настройки, установщик и политика обновлений; примеры - Debian, Ubuntu, Fedora
Отметим, что не каждая ОС на Linux является GNU/Linux, многие `embeded` проекты и android используются свои разработки `user space`. 


## Что такое ядро ОС? За что отвечает ядро Linux?

Ядро ОС - привилегированная часть ОС, которая управляет ресурсами и предоставляет программам из user space доступ к ним через системные вызовы
Ядро выполняет 5 основных функций:
1) Управление памятью
Выделение ресурсов программе, выделение физической памяти обработка ошибок получения данных и защита данных одной программы от другой.
2) Управление процессами
Ядро создаёт, завершает, планирует процессы/потоки, обрабаотывает сигналы и предоставлеят механизмы IPC
3) Взаимодействие драйверов устройств
4) Управление файловой системой
5) Сетевое взаимодействие
Работа с TCP, UDP. Обработка пакетов.
Пример: системный вызов `read` в `Linux`, которая позволяет прочитать поток байтов из файлового дескриптора, кем может являеться, как обычный файл, так и сокет. 


## Что такое shell? Какие оболочки ты знаешь?

shell - это оболочка над ОС. Shell - это интерпретатор команд и язык сценариев, который читает команды пользователя или скрипта, запускает программы и обрабатывает результат.
Внтури `shell` можно использовать и запускать множество команд: `ls`, `echo`, `cat`, `mv` и т.д.
Оболочек много, но наибольшую славу у разработчиков завоевали `bash` и `zsh` - которые предоставляют удобный текстовый редактор и удобство автодополнения.


## Что такое терминал, консоль и TTY? В чём различие?



`TTY` (`Teletype`) - в современных ОС `tty` обозначают текстовые терминалы и интерфейсы командной строки, которые позволяют взаимодействовать с системой через текстовые команды.

Каждое откртие терминала равносильно созданию псевдотерминала (программная эмуляция телетайпа)

Каждый псевдотерминал состоит из виртуальных устройств - `master` и `slave`
`Master` устройство выполняет роль эмулятора между терминалом и ОС. `Slave` предназначено для взаимодействия консольных приложений и ОС

Выполнив команду `tty` можно увидеть текущий дескриптор `slave` устройства.
```bash
tty
/dev/pts/1
```
Зная дескриптор `slave` устройства `tty` можно напрямую писать из другого терминала 
```bash
echo "Привет из второго терминала!" > /dev/pts/4
```

Каждая консоль создаёт уникальную пару: master + slave
- Master создаётся через специальное устройство `/dev/ptmx`, который возвращает файловый дескриптор, который и является `master`
- `Slave` представляет собой символьное устройство в виде файла и оно видно в файловой системе
